# 🐉 PawPlan — Make Progress, Not Panic

**A gamified assignment management platform designed to help students stay organised, focused and motivated.**

## 📌 About PawPlan

PawPlan is a student productivity web application that helps students manage their academic workload through assignment tracking, deadline reminders, focused study sessions and collaborative group planning.

Unlike traditional assignment trackers, PawPlan introduces an interactive dragon companion that rewards students for completing assignments on time. By combining productivity tools with gamification, PawPlan aims to make academic organisation more engaging and encourage consistent study habits.

## ✨ Key Features

### 1. Assignment Management
- Create and manage individual assignments.
- Set assignment deadlines and difficulty levels.
- Break assignments into smaller checklist tasks.
- Track assignment completion and progress.
- View active, submitted and missed assignments.

### 2. Dashboard
- View assignment statistics and progress.
- Monitor upcoming deadlines.
- Access personal reminders.
- Track dragon points and on-time submissions.

### 3. Reminders and Notifications
- Set personal reminders.
- Receive assignment deadline notifications.
- Keep track of important upcoming tasks.

### 4. Focus Mode
- Use a dedicated study timer.
- Choose from different session durations.
- Earn dragon points for completing focus sessions.
- Receive a penalty for stopping an active session early.

### 5. TeamSpace
- Create group assignment plans.
- Add team members and project tasks.
- Distribute tasks automatically according to difficulty or assign them manually.
- Track individual task progress and submission status.
- Set a group assignment deadline.

### 6. Interactive Dragon Reward System
- Earn dragon points through on-time submissions and completed focus sessions.
- Progress through dragon evolution stages.
- Experience different dragon animations and interactions.
- Lose points when deadlines are missed or focus sessions are stopped early.

## 💾 Data Storage and Limitations

- PawPlan currently stores application data using browser Local Storage.
- Saved data is specific to the browser and device being used.
- TeamSpace plans are not synchronised between different users or devices.
- The account system is a demonstration feature and is not production-grade authentication.
- Notifications depend on browser notification permissions and support.

## 🎯 Project Objective

PawPlan aims to make assignment management more engaging by combining organisation, productivity and gamification.

The goal is to encourage students to take smaller, consistent steps towards completing their academic responsibilities while making the learning process more rewarding.
